前置条件：给自己设定一个"高到近乎离谱"的时薪（纳瓦尔没钱时定 5000 美元/小时）

# 操作步骤
1. 定时薪：从当下到财务自由那天，选一个折中时薪；然后"再进一步提高"
2. 外包规则：外包成本 < 时薪 → 花钱外包，不要犹豫
3. 放弃规则：不做的损失 < 时薪 → 直接放弃（东西坏了直接扔/捐，不退换）
4. 购买规则：花钱请人 < 时薪 → 请人（包括为家人雇人办事）
5. 持续执行并定期上调时薪——"没有人会比你更看重自己"

# 判断标准
- 做每个时间决策前，脑海里自动换算"这件事值我多少钱"
- 你越来越少为琐事消耗时间，省下的时间流向专长和杠杆

# 常见失败模式
- 90% 的人卡在：嘴上说时间值钱，行动上仍为退一个便宜货跑断腿
- 把省钱当赚钱——"把时间花在省钱上是不会致富的，省出时间来赚钱才是正确的思路"
- 时薪定得太"合理"：理想的时薪应该高到近乎离谱，否则还不够高
