# 操作步骤
1. 放弃寻找"正确方法"，转而列出所有候选方案/路径
2. 逐一排查：哪个方案存在明显错误、致命缺陷、不可承受的下行风险？划掉它
3. 反复排除，直到剩下的选项没有已知错误
4. 执行并记住核心信条："成功的关键不在于做出正确判断，而在于避免做出错误判断"
5. 复盘时警惕归因偏差："当把成功归于自己时，要更加谨慎，难免出现认知偏差"

# 判断标准
- 你的决策日志里记录的是"排除了什么、为什么"，而不是"哪个看起来最好"
- 避免的错误随时间减少，而非"正确率"刻意提高

# 常见失败模式
- 90% 的人卡在：拼命比较哪个选项"最优"，在都差不多的选项间无限纠结
- 依赖记忆做预测式推理（"过去发生所以未来也会发生"）——纳瓦尔称这是最靠不住的逻辑
- 把一次好结果归因于自己的判断力，下次加大赌注
