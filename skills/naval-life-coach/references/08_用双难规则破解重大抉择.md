# 操作步骤
1. 规则一·难以抉择即否定：列完清单、权衡利弊后仍然难以抉择 → 答案就是否定的
   - 依据：现代社会选择成千上万，重大决策影响几十年，"一定要在非常确定的情况下再做决定"
2. 规则二·选短期更痛苦的路：两个选项利弊各占 50% 时，选短期内更艰难、更痛苦的那条
   - 依据：大脑会本能回避短期痛苦；而短期痛苦往往伴随长期收益，长期收益靠复利
3. 组合使用：先规则一筛掉"不笃定"，再规则二处理"打平手"
4. 自我训练：主动迎接短期痛苦（运动、读难书），压制回避倾向

# 判断标准
- 重大决定做出时是"笃定"而非"赌一把"
- 回顾时，你选的那些"当时难受"的路，长期回报明显高于舒服的路

# 常见失败模式
- 90% 的人卡在：把规则一用到小事上（午饭吃什么都"难以抉择即否定"）变成决策瘫痪
- 忽略规则二的前提"利弊各半"——明明一条路更差，却用"选痛苦的"自我感动
- 用"再想想"无限拖延，把"不决定"当成了决定
