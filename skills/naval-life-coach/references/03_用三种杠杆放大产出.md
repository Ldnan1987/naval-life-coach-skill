# 操作步骤
1. 识别当前杠杆：手头的事用的是哪种？
   - 劳动力杠杆（让别人干活）——最古老、争夺最激烈、管理最难，别过度追逐
   - 资本杠杆（用钱放大决策）——20 世纪新贵的杠杆，需要有人出资
   - 复制边际成本为零的产品（代码/媒体）——无需许可、睡觉时也赚钱【首选】
2. 向"无需许可的杠杆"迁移：会写代码就做软件；不会就出书、写博客、做视频、录播客
3. 逐级叠加：劳动力 + 资本 + 代码杠杆组合使用（房地产链条：维修工→承包商→开发商→基金经理→科技公司）
4. 检查产出形式：拒绝"投入产出强绑定"的支持性工作（如纯客服），选择创造性工作

# 判断标准
- 你睡着的时候，有资产/产品/内容在替你工作
- 现代人的二分法检验：你是"利用了杠杆的人"还是"没有利用杠杆的人"

# 常见失败模式
- 90% 的人卡在：只会在"升职加薪"的框架里努力，从不问"我的杠杆是什么"
- 误以为需要资本才能开始——代码和媒体杠杆只需要一台计算机
- 追逐劳动力杠杆带来的虚荣（"会让父母觉得你了不起"），陷入管理泥潭
