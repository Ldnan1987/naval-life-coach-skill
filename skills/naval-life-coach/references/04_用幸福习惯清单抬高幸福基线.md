# 操作步骤
1. 换掉坏习惯：戒酒戒糖戒咖啡因以稳定情绪；减少屏幕时间；远离社交媒体与新闻（"新闻的目的就是让人感到焦虑和愤怒"）
2. 建立幸福习惯（纳瓦尔自述有效的清单）：
   - 洞察冥想：意识到在评判别人时，问"我能不能正面解读这件事？"（目标：1 秒内完成）
   - 阳光 + 运动 + 正向思考（提升血清素）
   - 秘密越少幸福感越高；少用电话/日历/闹钟三个 App
   - 惶恐时用冥想、音乐、运动调整情绪，然后放下，把能量投入新事情
3. 选对五只黑猩猩：盘点最常相处的 5 个人——他们积极乐观吗？相处耗费心力吗？我对他们心怀钦佩而毫无嫉妒吗？远离经常参与冲突的人
4. 对外承诺：告诉朋友"我是一个幸福的人"，用一致性偏见逼自己言出必行
5. 按"改变习惯六步"执行：具象化愿望 → 可持续路径 → 确定需求/诱因/替代品 → 告诉朋友 → 严格自律 → 全面接受新的自我形象

# 判断标准
- 幸福指数公式自检：一天中多少时间用于追随兴趣，而非履行职责
- 情绪反应时间缩短：找到一件糟心事的积极面，从几秒练到瞬间

# 常见失败模式
- 90% 的人卡在：知道所有方法但一个都不试——"每个人都说自己在节食，实际上没有人真正在做"
- 把幸福当多人竞争游戏，追求外界认可（幸福训练是单人游戏，没人给你打分）
- 试图一次改掉所有习惯；正确节奏是"每六个月改掉一些坏习惯、养成一些好习惯"
