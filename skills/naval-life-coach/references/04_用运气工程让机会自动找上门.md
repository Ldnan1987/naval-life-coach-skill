# 操作步骤
1. 识别四种运气：
   - ①不期而遇（纯随机，不可控）
   - ②不停折腾撞上大运（靠行动量）
   - ③有准备的大脑对机会敏感（靠领域深耕）
   - ④打造独特个性/品牌/心态，让运气来找你【最高级】
2. 从 ②③ 做起：增加尝试次数 + 在本领域保持信息敏感度
3. 修炼 ④：把你做的事做到极致、名副其实，让别人遇到相关机会时第一个想到你（深海潜水员与宝船模型）
4. 同步经营人品与声誉：诚信正直、目光长远——"别人以为你是运气好，其实那是人品"
5. 玩长线游戏：主动付出、不计较回报，让合作者都想把好处分给你（埃拉德·吉尔模式）

# 判断标准
- 开始有"不知道哪来的机会"主动找你
- 陌生人谈合作时因你的声誉而选择通过你达成交易
- "因果关系确定时，运气就不再是运气"

# 常见失败模式
- 90% 的人卡在：只想 ① 等好运，不愿做 ②③ 的笨功夫，更没耐心养 ④ 的声誉
- 一边想被机会找到，一边做一两件"对别人不太好"的事毁掉声誉——失德会反噬
- 大谈特谈自己多诚实（警示信号：真正值得信赖的人不用宣扬）
