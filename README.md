# 纳瓦尔人生教练（Naval Life Coach）

基于《纳瓦尔宝典》（The Almanack of Naval Ravikant，埃里克·乔根森 编纂）提炼的 **14 张可执行人生指导技能卡**，打包为 Kimi 插件。覆盖四条主线：

- **财富创造**（4 张）：把自己产品化 / 时薪定价法 / 三种杠杆 / 运气工程
- **判断决策**（3 张）：反推法排除式决策 / 双难规则 / 直面现实三步
- **幸福修炼**（4 张）：欲望审计 / 三种选择终结纠结 / 百分百交换人生 / 幸福习惯清单
- **自我救赎**（3 张）：四种冥想法 / 广而告之锁死改变 / 晨练铁律

每张卡包含：技能名、来源章节、使用频率星级、适用场景、前置条件、操作步骤、判断标准、常见失败模式（90% 的人卡在哪）。

## 使用方式

在 Kimi 桌面版插件页「个人」页签安装后，用自然语言提需求即可触发，例如：

- "我想搞副业但不知道做什么方向，给我把把脉"
- "我在纠结要不要辞职去另一个城市，帮我理一理"
- "最近总是很焦虑，想要的东西特别多"

## 配套插件

[批判性思维教练](https://github.com/Ldnan1987/critical-thinking-coach-skill)：纳瓦尔卡管人生决策，论证卡管观点表达与辩论。

## 目录结构

```
kimi.plugin.json
skills/naval-life-coach/
├── SKILL.md            ← 教练工作流（诊断主线 → 选卡 → 按卡执行）
└── references/         ← 14 张技能卡
```
